# Reading Edition · Visual Profile Candidate

状态：**CANDIDATE / NOT FROZEN**。本文件说明当前出版参数和检查边界，不替代 Editorial Profile、冻结 Markdown 或发布批准。实现位于 [共享组件](../../latex/kb-base.sty)、[渲染过滤器](../../engine/filters/blocks.lua)及两个产品 profile；不新增另一套构建引擎。

## 字体与层级

正文保持 11 pt，代码保持 9 pt / 12 pt 行距，表格保持 9.5 pt / 13 pt。主标题使用无衬线深蓝，主要节使用 16/21 pt 青绿，次节使用 12/16 pt 深蓝。源 Markdown 层级与 PDF 导航层级保留，视觉角色由 profile 映射：C++ 文档标题为章、H2 为主要节、H3 为次节；ESD 文档标题为章，其后的 H1/H2/H3 分别为主要节、次节和条款层。

Balanced 是当前主候选。Compact 保持相同字体与字号，仅将主要节前/后距从 18/8 pt 改为 12/5 pt，次节从 12/5 pt 改为 8/4 pt，字段距从 4 pt 改为 2 pt，表格伸展系数从 1.2 改为 1.08，目录附加间距从 1 pt 改为 0。不能用 Compact 的页数较少推导阅读质量更高。

## 分页与组件

| 对象 | 当前策略 | 边界 |
| --- | --- | --- |
| 标题链 | 按实际字体测量相邻标题，保留首块空间；表格/代码另加预算 | 是保守空间预算，不是理解全部自然语言结构 |
| 短表 | 估计折行预算不超过 profile 的 `short_table_lines=12` 时整表保留 | 阈值是估算行数而非精确毫米；生成后核对起止页 |
| 长矩阵 | 允许跨页，重复表头，不把最后边线单独移页 | RACI、风险比较继续保持矩阵 |
| 短记录 | 小于 550 字符且不超过 9 字段时整条保留 | 不承诺任意字号、任意嵌套内容均适用此启发式 |
| 长记录 | 单个标签—值字段组不可拆，记录可跨页，续页保留身份 | 检查单字段残尾；未实现任意业务自定义多字段分组或超页大字段拆分 |
| 空字段 | 横线明确表示源表空值；无数据行的表保留全部字段名 | 不生成虚构填写值，不把空表模式误登记为已填写记录 |
| 完整实验 | 显示出版块 ID、实验 ID、文件名，跨页重复身份 | 不增加源码行号；原始附件保留完整字节 |
| 机制片段 | 轻量框线，不重复续页标题 | 不承诺独立可编译 |
| ASCII/空间流程 | 严格等宽，不静默软折行，超宽失败 | 不重新绘制原图或补充边关系 |
| 字面文本/Console | 允许软折行，续行悬挂缩进与向量提示 | 提示不是文本字符；复制时空白仍取决于 PDF 阅读器 |
| 代码头尾 | 默认至少 4 行头部、6 行尾部；纯闭合尾额外带 3 行上下文；不超过 16 行整块保留 | 源行预算而非 C++ 语法分析，不保证按完整语句分页 |
| Final Gate | 数字题号与首句同排；加粗 A/B/C 类分组标签保留后续题目空间 | 只组合原有排版单位，不改题目、答案或技术判据 |

表格策略接受 `comparison / simple / record / template`，并兼容旧 `matrix / records`。显式业务比较策略优先；未指定的表仍采用保守默认选择，不宣称已完成所有表的人工任务分类。

## 导航与身份

合订目录显示文档/章与主要节，书签保留更深结构。冻结正文原有章内目录标记为 `CHAPTER READING PATH`；条款索引、跨文档目的地与 Final Gate 承担回查入口。页眉保留文档 ID 和主要节，页脚保留 PREVIEW / DRAFT；完整版本、源提交、准备标识放在封面、控制页与章首。

C++ 章首新增 `SOURCE SNAPSHOT CONTENT` 提示，解释原稿中历史 `NOT BUILT / NOT VALIDATED` 与当前 Pilot 的关系。该提示是生成内容，不能替代或改写原文。生成条款索引切换自己的页眉，不沿用正文最后一节。

## 审计身份

`reading-components.json` 保留源码行与生成组件身份；PDF named destinations 将源行、表格和字段绑定到实际页。`page-map.json` 检查短表跨页、代码头尾、纯闭合残尾、实验身份、记录单字段残尾、异常目录尾页等信号。源行间距较大只标记 `wrap_or_chunk_spacing`，不是自动确认软折行。

`STRUCTURAL_PASS` 不等于视觉证明。代表 PNG 的实际查看、接受的留白与剩余限制单独记录；未查看的页面不能因为已成功渲染就称为目视通过。字体、字号和密度的最终冻结仍需集中审核；本批不启动 G0～G12 全量出版或正式发布。

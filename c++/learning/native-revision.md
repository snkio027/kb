重点修正与补全：

- 源函数不必对应最终保留符号；C 语言链接属性不等于统一符号拼写、导出或对象 ABI 转换。
- PImpl 保留工具链与公开类自身的 ABI，涉及不完整类型删除的定义位置要受控；不把 unique_ptr 大小说成语言保证。
- noexcept 不自动翻译异常，声明与定义须匹配。合并原稿互不一致的 create/decode 片段，完整实现以 G8-B2 为唯一源码。
- struct_size 不是任意指针有效性检查；尾部追加字段须逐项检查范围，不执行不兼容布局的未定义行为“演示”。
- 静态库 PRIVATE 依赖仍可能参与消费者最终链接及包导出；归档依赖边不表示物理嵌入依赖 archive。
- CMake 生成器表达式保持完整参数，语言模式要求不等于标准库设施已实现；版本配置接受规则不是 ABI 检测。
- 预设、模块、CPS、包管理器和跨平台能力保留版本/执行边界，删除“最新稳定版”永久事实式措辞及聊天引用占位符。

技术回查使用正文链接的固定 N4950、CMake 4.4 文档线及平台/语言官方资料。官方资料回查与本地执行是不同证据；本地链接检查不验证互联网 URL。

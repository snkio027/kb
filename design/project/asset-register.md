| 接收描述 | 本表含义 |
| --- | --- |
| 已定位并核对 | 文件或记录实际可读，已完成所列范围的核对；不是全面审定 |
| 已接收、待兼容性或证据复核 | 已有实体，但是否适用于当前基线尚未确定 |
| 历史提及、尚未接收 | 仅获知名称、版本或完成声明，未取得对应文件或完整证据链 |
| 拟交付 | 计划中的未来成果；不计为已接收资产 |

这些是接收描述，不是 Claim、Evidence、Gate 或符合性的新状态枚举。原始事实与后续授权仍按 GOV/ASSURANCE 分开。
